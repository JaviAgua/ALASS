# ALASS: Assessment of Language in Adults using Self-reported Skills

A free, 31-item self-report questionnaire on adults' language skills, as recalled in early childhood and as they are now.

**Take or score it online:** open `index.html` (published with GitHub Pages). Answers are scored in the browser. Nothing is stored or sent.

**Printable version and scoring key:** `ALASS_31_items.pdf`.

## Scores

Every item is rated from 1 ("I'm not very good") to 10 ("I'm very good"). Each score is the mean of the items answered:

| Score | Items |
|---|---|
| Childhood Language (CL) | A1–A13 |
| Language Performance (LP) | B1, B2, B4, B8–B18 |
| Social Use of Language (SUL) | B3, B5, B6, B7 |
| Total | all 31 items |

The page also shows each score as a percentile of a reference sample: 130 first-year psychology students at one UK university (2025 and 2026 cohorts). This is a comparison group, not a set of population norms.

The ALASS is a research and screening questionnaire, not a diagnostic test. It has no validated cut-off scores.
